## EPYC Milan VPS 的「独占核心」到底是什么意思

市面上多数便宜的「EPYC VPS」卖的是共享 vCPU：一个物理核心被切成几份卖给不同用户，邻居一忙你的性能就掉。GreenCloud 的 EPYC VDS 宣传页写的是「100% Physical CPU cores, RAM and RAID-10 NVMe 4.0」，也就是物理核心不和别人分，内存和 NVMe 4.0 阵列同样独占。

这个差别有多大？可以看同行的做法：有的服务商明确把 Milan 系列定位为共享 vCPU，分配比 1:2 到 1:4，只有更贵的 Genoa（Zen 4）才给独占核心；有的低价 Milan VPS 从 $3.89/月起，走的是成本优化路线。$10/月买到独占物理核心，在这个市场里属于比较少见的定价，代价是起步价高于纯共享方案，且系统只支持 Linux。

至于用途，这套配置适合的是对 CPU 稳定性敏感的场景：生产数据库、常驻编译、游戏服、需要稳定算力的爬虫或数据处理。纯建站、挂博客这种轻负载，用更便宜的共享方案反而更划算，没必要为一个用不满的独占核心多花钱。

## 退款、附加服务和条款里的坑

GreenCloud 的服务是无管理（unmanaged）的：硬件问题他们管，软件配置问题自己解决。这一条买之前要想清楚，没有运维能力的话，便宜 VPS 省下的钱可能都赔在折腾上。

条款里几条直接影响钱包的规则，整理如下：

- **7 天退款**只给新客户的首个 VPS，且不含 cPanel、DirectAdmin 这类附加服务
- **加密货币付款一律不可退**；促销套餐、独立服务器、代理均不可退
- 用掉 **10% 及以上分配流量**的订单失去退款资格
- 加流量：美国/欧盟 $3/TB/月，亚太 $15/TB/月——亚太加了 4 倍价，印证了前面说的流量差异
- 加 IP：美国 $2/IP/月，欧盟/亚太 $3/IP/月，每台 VPS 最多 5 个

- 发票逾期 2 天收 10% 滞纳金，到期 1 天可暂停、3 天可终止；发起 PayPal 或信用卡拒付会直接导致所有服务被停

**EPYC Milan VPS 适合跑什么？**
